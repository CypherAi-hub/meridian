## Measured runtime evidence

**Authenticated update:** the user supplied existing provider credentials. Helius mainnet RPC and Jupiter V2 quote-only requests both passed real HTTP 200 tests. Keys are in an ignored, user-restricted local `.env`; no account signup, funded wallet, or live transaction was needed. The full transaction enrichment queue can still be overloaded by all-program traffic. This is reported separately from the fast typed-event observer.

The new finalized typed-event path decoded more than 15,000 actual events in a runtime check with p95 around **1 ms from local notification receipt through observation processing**, zero callback drops, and zero callback errors in that snapshot. This excludes validator-to-observer and finality latency; it is not first-block execution. Full transaction enrichment remained degraded. The dashboard now shows both timers and explicit verification status. Four real quote-research samples had been collected at the same check; none are counted as trades or profits.

Python analysis is implemented and run against the actual worker state. The current report is **INSUFFICIENT_OUT_OF_SAMPLE_EVIDENCE**, with zero completed positions. It never counts a positive quote-only round trip as realized earnings. Partial exits are attributed to one completed position before calculating position win rates.

On 2026-10-26, a Windows mainnet public-RPC run received more than 25,000 actual transaction notifications and decoded real Pump/PumpSwap/Raydium CPMM transactions, with explorer-link signatures visible in the Next dashboard. Example finalized Pump regression: `5rDXhYfpZh38wiJrBGSv3Wbaktqp66YfigXtuMY6wxP9dxhjwHvDGcoJA5GAyr7xz3Y9bVHWqmAFBC7aEFMLr4w9`, slot `461770647`. Official current layouts alone did not decode its historical instruction; the decoder now selects an exact-byte pinned historical layout. The exact event layout is now covered by the pinned SDK IDL; its parent instruction/event label mapping still requires independent evidence and vetoes execution.

The overloaded public feed showed roughly 52 seconds p50 and 100 seconds p95 local-receipt-to-processing latency in one snapshot, with queue 500 and coverage gaps. These are poor execution timings, not a performance achievement. The values include local queueing and HTTP fetch; they do not measure validator-to-observer delay. See the saved runtime evidence for a fresh snapshot. The code has no assertion that the public feed is complete or suitable for launch sniping.

Unit/integration tests use observable state or explicitly synthetic fixtures. Mainnet ingestion is real; paper funds are simulated. Zero completed live-collection paper trades means there is no measured profitable strategy or live-fill benchmark yet.

## External dependencies and unresolved gates

1. Authenticated Helius RPC is now configured on Windows. Yellowstone streaming still needs a real endpoint/token for runtime throughput and replay validation. Full all-program transaction enrichment cannot be assumed complete merely because the typed-event observer is fast.
2. A dedicated loopback PostgreSQL 18.4 validation server now tests real migrations, exact JSON amounts, deduplication, competing workers, interrupted writes, and terminated advisory-lock backends. Worker SQL is fenced through the actual lock-holding session; lease loss permanently suspends the old worker and engine settlement. CI runs these tests against its own PostgreSQL 18 service. The running research worker still uses its original PGlite warehouse; no data migration or production PostgreSQL deployment is claimed.
3. Jupiter is now configured and verified on Windows. Pump native-SOL reserve quotes remain a constrained alternative. User-supplied keys are kept out of source, logs, artifacts, and the Mac coordination messages.
4. Complete holder/creator relationship evidence, sufficient recorded quotes, and reviewed out-of-sample artifacts are required before adaptive strategies or positive performance claims.
5. The pinned official SDK dependency graph retains the unpatched `bigint-buffer` native-extension advisory GHSA-3gc7-fjrx-p6mg. Compatible dependency overrides removed unrelated advisories; no breaking SDK downgrade was applied. Install with `--ignore-scripts` so the affected optional native extension is not built; the research runtime uses its JavaScript fallback. This remains a production review item, not a claim of a clean vulnerability audit.
6. No automated capital transfer, payout, wallet creation, funded trade, signing, or real swap was performed. Live enablement is outside the current paper CLI and requires a separate explicit user decision and security review.

Raw JSON RPC and Yellowstone observations now recognize validated v1 configuration without confusing its total priority fee with a per-compute-unit price. The real finalized v1 fixture and installed protobuf codec are covered by tests. This is read-only support; v1 observations cannot authorize execution, and the pinned SDK is not claimed to decode or sign raw v1 transactions. The existing Helius free plan explicitly rejected `transactionSubscribe` in a bounded capability probe; no paid upgrade occurred. See `DATA-SOURCE-RESEARCH.md` for primary documentation and the remaining provider gates.
