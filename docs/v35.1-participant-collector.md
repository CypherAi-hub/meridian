# V3.5.1 Prospective Participant Collector

Connects V3.5 Shadow Sniper to **real** Helius parsed transactions.

## Isolation

| | Production | This collector |
|---|---|---|
| Branch | `main` | `v35.1-participant-collector` |
| Worker | `npm run worker` | `npm run shadow-collector` |
| Lease | `meridian_primary_research_writer` | `meridian_v35_shadow_collector` |
| Database | `DATABASE_URL` | `PARTICIPANT_DATABASE_URL` or `DATABASE_URL_DEV` |
| Migration 0012 | **do not apply** | `npm run v35:migrate` on the **dev** DB only |

If `PARTICIPANT_DATABASE_URL` equals `DATABASE_URL`, boot fails.

## Run (dev)

```
PARTICIPANT_DATABASE_URL=postgres://... \
HELIUS_API_KEY=... \
SHADOW_WATCH_MINTS=mint1,mint2 \
SNIPER_MODE=SHADOW \
V35_PERSIST=1 \
npm run shadow-collector
```
